# Ferry 1.0.0

> English | [简体中文](1.0.0.zh-Hans.md)

Ferry 1.0.0 is the first versioned release of the Ferry Server and Web app: a self-hosted timeline for moving text, links and files between your devices on a private network.

## What's new

- **Install without cloning.** A public image, `ghcr.io/max1874/ferry:1.0.0`, runs on `linux/amd64` and `linux/arm64`. The deployment bundle below holds everything Compose needs.
- **Connect another device.** An empty timeline explains what to do next. **Devices** now shows the server address with a copy button and a QR code generated in your browser. The code carries only the address, never a device token or password.
- **Clearer startup log.** Ferry prints the address it listens on and, separately, the address to open in a browser, including a warning when that address works on this computer only.
- **A browser is enough.** Phones and computers join from the browser; nothing needs to be installed on them.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.0/ferry-1.0.0-deploy.tar.gz
tar -xzf ferry-1.0.0-deploy.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The README covers every step, other deployment paths and troubleshooting.

## Upgrade an existing source deployment

In the directory you already deploy from:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.0.tar.gz
git pull --ff-only
docker compose pull
docker compose up -d
```

Compose keeps the same service, volume, data directory and user, so messages, files, device identities and the password carry over. Later upgrades change only the version in `FERRY_IMAGE`.

## Limits

- Ferry serves plain HTTP for a trusted private network. Keep it off the public Internet; a TLS reverse proxy of your own inside the private network is supported.
- The native iOS and Android apps are not part of this release.

# Ferry 1.0.5

> [English](1.0.5.md) | 简体中文

部署 Server + Web 应用请下载 **`ferry-1.0.5-docker-compose.tar.gz`**；使用可选的 Android App 请下载 **`FerryDrop-1.0.1-3.apk`**。

## 改动

- **复制和撤回变成每条消息下方的图标。** 消息上方那一行只保留设备和时间。内容下方是复制图标（文字进入剪贴板后变成对勾）和撤回用的垃圾桶图标（仍会先确认）。Web、iOS、Android 都一样。
- **手机端时间线读起来像对话。** 在 iOS 和 Android 上，其他设备发的消息是占满宽度的正文，上方一行小字“设备 · 时间”；你手上这台设备发的消息放在右侧气泡里。去掉了头像列和彩色文件方块。
- **Web 复制失败时不再卡住。** 浏览器拒绝写入剪贴板时，Ferry 会选中消息文字，直接按复制快捷键即可；不再在什么都没选中的情况下提示按 Ctrl+C。
- **Android App 1.0.1。** 本版附带稳定发布签名的 FerryDrop APK，App 版本 **1.0.1**、versionCode **3**，与 1.0.0 (2) 使用同一证书，可直接覆盖升级。

API、存储和撤回行为没有变化。OpenAPI 描述补上了服务器一直随消息返回的 `is_current_device`。iOS 单独分发，已有内部 TestFlight 测试员可更新至 **1.0.1 (2)**。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.5/ferry-1.0.5-docker-compose.tar.gz
tar -xzf ferry-1.0.5-docker-compose.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改为这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

Compose 部署包包含配置和备份脚本，Docker 会拉取支持 `linux/amd64`、`linux/arm64` 的 `ghcr.io/max1874/ferry:1.0.5`。GitHub 自动附带的源码归档供开发者使用。

Android 下载并打开 `FerryDrop-1.0.1-3.apk`，如有提示则允许该来源安装。它会直接覆盖升级上一版的 FerryDrop 1.0.0 (2)，保留 App 的连接。debug/开发包使用不同证书，无法直接覆盖升级。

## 升级

在现有的 `ferry` 目录里，先备份：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.5.tar.gz
```

在 `.env` 中设置 `FERRY_IMAGE=ghcr.io/max1874/ferry:1.0.5`，然后运行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

消息、文件、设备和共享密码会保留。

## 验证与限制

新的消息行在运行中的 Server 上验证过：Web 在 Chromium 的桌面宽度和 390 px 宽度下，iOS 模拟器在浅色和深色外观下；复制把原文放进剪贴板，撤回会先确认，从 Web 撤回的消息在 iOS 上消失。附件 APK 已在真实 Android 手机上覆盖 1.0.0 (2) 安装并启动，但当时那台手机连不上它的服务器，所以没有用真实消息看到新的 Android 时间线；此前同一图标行的一个构建在那台手机上看过，复制可用、撤回确认正常。实际 iPhone 验收仍然暂缓。

Ferry 使用明文 HTTP，适用于可信私有网络，不支持暴露到公网；支持在私有网络内使用自己的 TLS 反向代理。

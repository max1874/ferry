# Ferry 1.0.1

> [English](1.0.1.md) | 简体中文

Ferry 1.0.1 是 Ferry Server 和 Web 应用的一次小更新。你的消息、文件、设备和密码都不受影响。

## 我该下载哪个文件？

- **新安装：下载 `ferry-1.0.1-docker-compose.tar.gz`。** 它不是程序本身，而是 Docker Compose 需要的三个文件：`compose.yaml`、`.env.example` 和备份脚本。之后由 Compose 拉取程序本体，也就是公开镜像 `ghcr.io/max1874/ferry:1.0.1`，支持 `linux/amd64` 和 `linux/arm64`。
- **已经在运行 1.0.0？** 不需要下载，见[从 1.0.0 升级](#从-100-升级)。
- **Source code (zip / tar.gz)** 是 GitHub 自动附带给开发者的源码。运行 Ferry 不需要它。

## 改动

- **重画了 Web 应用的图标。**
- **Docker 里的启动日志更清楚。** 第一行现在会说明 Ferry 监听的是容器内部的地址，免得被当成要打开的地址。下一行仍然给出真正要打开的地址。
- **`compose.yaml` 不再固定时区。** 1.0.0 设置了 `TZ: Asia/Shanghai`，但镜像里没有时区数据，这项设置从来没有生效。日志时间过去和现在都是 UTC。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.1/ferry-1.0.1-docker-compose.tar.gz
tar -xzf ferry-1.0.1-docker-compose.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改成这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

README 里有完整步骤、其他部署方式和排错说明。

## 从 1.0.0 升级

在你的 `ferry` 目录里，先备份：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.1.tar.gz
```

把 `.env` 里的 `FERRY_IMAGE` 改成 `ghcr.io/max1874/ferry:1.0.1`，然后运行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

你也可以删掉 `compose.yaml` 里的 `TZ: Asia/Shanghai` 这一行；留着也没有任何影响。

## 限制

- Ferry 为可信私有网络提供明文 HTTP。请不要把它暴露到公网；支持在私有网络内使用你自己的 TLS 反向代理。

# Ferry 1.0.0

> [English](1.0.0.md) | 简体中文

Ferry 1.0.0 是 Ferry Server 和 Web 应用的第一个正式版本：一条自托管的时间线，用来在私有网络里的设备之间摆渡文字、链接和文件。

## 新内容

- **不用克隆就能安装。** 公开镜像 `ghcr.io/max1874/ferry:1.0.0` 支持 `linux/amd64` 和 `linux/arm64`。下方的部署包里有 Compose 需要的一切。
- **连接另一台设备。** 空时间线会说明下一步做什么。**Devices** 页面现在显示服务器地址、复制按钮，以及在浏览器本地生成的二维码。二维码只包含地址，从不包含设备 token 或密码。
- **更清楚的启动日志。** Ferry 会分别打印监听地址和要在浏览器里打开的地址；如果这个地址只有本机能打开，也会明确提示。
- **有浏览器就够了。** 手机和电脑用浏览器加入，不需要安装任何东西。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.0/ferry-1.0.0-deploy.tar.gz
tar -xzf ferry-1.0.0-deploy.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改成这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

README 里有完整步骤、其他部署方式和排错说明。

## 升级现有的源码部署

在你原来的部署目录里运行：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.0.tar.gz
git pull --ff-only
docker compose pull
docker compose up -d
```

Compose 保持同样的服务名、数据卷、数据目录和运行用户，所以消息、文件、设备身份和密码都会保留。以后升级只需修改 `FERRY_IMAGE` 里的版本号。

## 限制

- Ferry 为可信私有网络提供明文 HTTP。请不要把它暴露到公网；支持在私有网络内使用你自己的 TLS 反向代理。
- iOS 和 Android 原生 App 不属于本次发布。

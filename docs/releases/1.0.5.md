# Ferry 1.0.5

> English | [简体中文](1.0.5.zh-Hans.md)

Download **`ferry-1.0.5-docker-compose.tar.gz`** to deploy the Server + Web app, or **`FerryDrop-1.0.1-3.apk`** for the optional Android app.

## What's changed

- **Copy and Recall are icons under each message.** The line above a message now holds only the device and time. Under the content sit a copy icon, which turns into a checkmark once the text is on the clipboard, and a trash icon for Recall, which still asks for confirmation. This applies to Web, iOS and Android.
- **The phone timeline reads like a conversation.** On iOS and Android, messages from other devices are plain full-width text with one small “device · time” line, and messages from the device you are holding sit in a bubble on the right. The avatar column and the coloured file tiles are gone.
- **Copying on Web no longer leaves you stuck.** When the browser refuses to write the clipboard, Ferry now selects the message text so your copy shortcut works, instead of asking you to press Ctrl+C with nothing selected.
- **Android app 1.0.1.** This release includes the stable-signed FerryDrop APK, app version **1.0.1**, versionCode **3**, signed with the same certificate as 1.0.0 (2), so it updates the earlier APK in place.

No API, storage or recall behaviour changed. The OpenAPI description now documents `is_current_device`, which the server has always returned with each message. iOS is distributed separately; the update is available to existing internal TestFlight testers as **1.0.1 (2)**.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.5/ferry-1.0.5-docker-compose.tar.gz
tar -xzf ferry-1.0.5-docker-compose.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The Compose bundle contains configuration and the backup script. Docker pulls `ghcr.io/max1874/ferry:1.0.5` for `linux/amd64` or `linux/arm64`. GitHub's source archives are for developers.

On Android, download and open `FerryDrop-1.0.1-3.apk` and allow installation from that source if prompted. It updates FerryDrop 1.0.0 (2) from the previous release in place, keeping the app's connection. A debug or development APK has a different signing certificate and cannot be updated in place.

## Upgrade

In your existing `ferry` directory, back up first:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.5.tar.gz
```

Set `FERRY_IMAGE=ghcr.io/max1874/ferry:1.0.5` in `.env`, then:

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

Messages, files, devices and the shared password are retained.

## Verification and limits

The new message rows were exercised in a running Server with Web in Chromium at desktop and 390 px widths, and in the iOS Simulator in light and dark appearance: copying put the exact text on the clipboard, Recall asked for confirmation, and a message recalled from Web disappeared on iOS. The attached APK was installed over 1.0.0 (2) on a real Android phone and launched, but that phone could not reach its server at the time, so the new Android timeline was not seen with real messages; an earlier build of the same icon row was seen there, with a working copy and the recall confirmation. Actual-iPhone verification is still deferred.

Ferry uses plain HTTP on a trusted private network. Public-Internet exposure remains unsupported; your own TLS reverse proxy inside a private network is supported.

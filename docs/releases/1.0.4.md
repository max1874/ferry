# Ferry 1.0.4

> English | [简体中文](1.0.4.zh-Hans.md)

Download **`ferry-1.0.4-docker-compose.tar.gz`** to deploy the Server + Web app, or **`FerryDrop-1.0.0-2.apk`** for the optional Android app. Upgrade the server first, then update every native client that needs live recall.

## What's changed

- **Recall text, images and files from any connected device.** Every message has a Recall action with confirmation. There is no time limit or original-device restriction, including for older messages. All admitted devices share this permission in Ferry's trusted space.
- **Remove recalled content across updated clients.** The message disappears from their timelines, open image previews close, and server file bytes are deleted. Old file URLs and download tickets return 404. Recall stays effective after reconnecting or restarting the server.
- **Retry failed recalls.** If file deletion fails, the message stays visible with an error and can be recalled again; clients are not told it succeeded prematurely.
- **Install Android directly.** This release includes the stable-signed FerryDrop Android APK, app version **1.0.0**, versionCode **2**, for Android 8+. The server release number and native app versions are independent.

Recall cannot remove copies, completed or in-flight downloads, or backups. Older clients may retain already loaded messages until reloaded or reconnected; update them for live removal. iOS is distributed separately; the recall update is available to existing internal TestFlight testers as **1.0.1 (1)**.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.4/ferry-1.0.4-docker-compose.tar.gz
tar -xzf ferry-1.0.4-docker-compose.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The Compose bundle contains configuration and the backup script. Docker pulls `ghcr.io/max1874/ferry:1.0.4` for `linux/amd64` or `linux/arm64`. GitHub's source archives are for developers.

On Android, download and open `FerryDrop-1.0.0-2.apk`, allow installation from that source if prompted, and connect to your upgraded server. A previous debug/development APK may have a different signing certificate and cannot be updated in place. Preserve any local app data before removing it; reconnecting creates a new device identity, while history and files remain on the server.

## Upgrade

In your existing `ferry` directory, back up first:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.4.tar.gz
```

Set `FERRY_IMAGE=ghcr.io/max1874/ferry:1.0.4` in `.env`, then:

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

Messages, files, devices and the shared password are retained. Recall deletes only content you explicitly confirm.

## Verification and limits

The recall implementation was exercised in running Server/Web, iOS Simulator and real Android environments. The attached APK is the pristine signed package installed on the Android device after native send, byte-preserving file download and cross-device recall verification. Actual-iPhone recall verification is deferred; TestFlight availability does not establish that runtime result.

Ferry uses plain HTTP on a trusted private network. Public-Internet exposure remains unsupported; your own TLS reverse proxy inside a private network is supported. Chromium browsers may require allowing insecure content or keeping a blocked download for an HTTP server.

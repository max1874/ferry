# Ferry 1.0.4

> [English](1.0.4.md) | 简体中文

部署 Server + Web 应用请下载 **`ferry-1.0.4-docker-compose.tar.gz`**；使用可选的 Android App 请下载 **`FerryDrop-1.0.0-2.apk`**。先升级服务端，再更新所有需要实时同步撤回的原生客户端。

## 改动

- **任意已连接设备都能撤回文字、图片和文件。** 每条消息都有 Recall 按钮，并在操作前确认。不限时间、不限原发送设备，也包括旧消息。Ferry 的可信空间内，所有已加入设备共享此权限。
- **已更新客户端同步移除撤回内容。** 消息从时间线消失，已打开的图片预览关闭，服务器上的文件字节被删除。旧文件地址和下载票据返回 404。重新连接或重启服务器后，撤回仍然有效。
- **撤回失败后可以重试。** 文件删除失败时，消息保留并显示错误，可重新撤回；不会提前告诉客户端已经成功。
- **Android 可以直接安装。** 本版附带稳定发布签名的 FerryDrop APK，App 版本为 **1.0.0**、versionCode 为 **2**，支持 Android 8 及以上。服务端发布号与原生 App 版本号各自独立。

撤回无法移除已经复制的内容、已完成或正在进行的下载，以及备份。旧客户端可能保留已经加载的消息，直到刷新或重新连接；实时移除需要更新客户端。iOS 单独分发，已有内部 TestFlight 测试员可更新至支持撤回的 **1.0.1 (1)**。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.4/ferry-1.0.4-docker-compose.tar.gz
tar -xzf ferry-1.0.4-docker-compose.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改为这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

Compose 部署包包含配置和备份脚本，Docker 会拉取支持 `linux/amd64`、`linux/arm64` 的 `ghcr.io/max1874/ferry:1.0.4`。GitHub 自动附带的源码归档供开发者使用。

Android 下载并打开 `FerryDrop-1.0.0-2.apk`，如有提示则允许该来源安装，然后连接升级后的服务端。以前安装的 debug/开发包可能使用不同证书，无法直接覆盖升级。卸载前保留需要的本地 App 数据；重新连接会创建新设备身份，历史和文件仍保存在服务器。

## 升级

在现有的 `ferry` 目录里，先备份：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.4.tar.gz
```

在 `.env` 中设置 `FERRY_IMAGE=ghcr.io/max1874/ferry:1.0.4`，然后运行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

消息、文件、设备和共享密码会保留。撤回只删除你明确确认的内容。

## 验证与限制

撤回实现在运行中的 Server/Web、iOS 模拟器和真实 Android 设备上走过验证。附件 APK 是完成原生发送、文件原字节下载和跨设备撤回验证后装回 Android 手机的正式签名包。实际 iPhone 的撤回验收暂缓；TestFlight 可用不等于已完成这项运行验收。

Ferry 使用明文 HTTP，适用于可信私有网络，不支持暴露到公网；支持在私有网络内使用自己的 TLS 反向代理。Chromium 浏览器面对 HTTP 服务时，可能需要允许不安全内容或在下载列表里保留被拦截的文件。

# Ferry 1.0.1

> English | [简体中文](1.0.1.zh-Hans.md)

Ferry 1.0.1 is a small update to the Ferry Server and Web app. Your messages, files, devices and password are not touched.

## Which file do I need?

- **New install: download `ferry-1.0.1-docker-compose.tar.gz`.** It is not the program itself but the three files Docker Compose needs: `compose.yaml`, `.env.example` and the backup script. Compose then pulls the program, the public image `ghcr.io/max1874/ferry:1.0.1`, for `linux/amd64` or `linux/arm64`.
- **Already running 1.0.0?** You do not need the download; see [Upgrade from 1.0.0](#upgrade-from-100).
- **Source code (zip / tar.gz)** is added by GitHub for developers. You do not need it to run Ferry.

## What's changed

- **Redrawn app icon** in the Web app.
- **Clearer startup log in Docker.** The first line now says that the address Ferry listens on is inside the container, so it is not mistaken for the address to open. The next line still names the address to open.
- **No fixed time zone in `compose.yaml`.** 1.0.0 set `TZ: Asia/Shanghai`, but the image carries no time-zone data, so the setting never took effect. Log times were and remain UTC.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.1/ferry-1.0.1-docker-compose.tar.gz
tar -xzf ferry-1.0.1-docker-compose.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The README covers every step, other deployment paths and troubleshooting.

## Upgrade from 1.0.0

In your `ferry` directory, back up first:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.1.tar.gz
```

Change `FERRY_IMAGE` in `.env` to `ghcr.io/max1874/ferry:1.0.1`, then:

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

You can also delete the `TZ: Asia/Shanghai` line from your `compose.yaml`; keeping it changes nothing.

## Limits

- Ferry serves plain HTTP for a trusted private network. Keep it off the public Internet; a TLS reverse proxy of your own inside the private network is supported.
